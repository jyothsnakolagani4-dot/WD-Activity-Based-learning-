# CampusCompass — Student Academic Dashboard

## Overview
A responsive academic dashboard concept that brings sample student information into one interface.

## Sections
- Sidebar navigation
- Student greeting and semester badge
- Attendance, average score, subject count, and upcoming exam cards
- Subject-wise attendance progress bars
- Campus announcements
- Subject and marks table
- Sample examination schedule
- Results summary

## Technologies
HTML5 and CSS3 only. The layout uses CSS Grid, Flexbox, tables, media queries, and styled progress bars.

## Run locally
Open `index.html` in a browser. Keep `style.css` in the same folder.

## Important
All student names, marks, attendance values, announcements, and examination dates are fictional sample data for demonstration. This is a static front-end prototype; it is not connected to a college database.
