## How to run
1. Open the desired project folder.
2. Double-click `index.html`, or open it in a browser.
3. To edit the project, open `index.html` and `style.css` in Visual Studio Code.

## Notes
- These are educational front-end prototypes. Forms, search fields, and action buttons are visual demonstrations and do not submit data or perform real bookings/enrollments.
- Package prices, grades, attendance, schedules, and student information are sample data for demonstration only.
- Some destination/course images are loaded from Unsplash and require an internet connection.
