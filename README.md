# Web Development ABL Projects

A collection of three beginner-friendly web development case studies built using **HTML5 and CSS3 only** for an Activity-Based Learning (ABL) assignment.

## Projects

### 1. WanderWay Travels — Travel Agency Website
A travel agency landing page featuring destinations, holiday packages, sample itineraries, and a travel inquiry form.

Folder: `travel-agency/`

### 2. SkillSpring — Online Learning Platform
An e-learning landing page featuring course categories, course cards, instructor information, and sample learning progress.

Folder: `online-learning/`

### 3. CampusCompass — Student Academic Dashboard
A student dashboard concept featuring student details, attendance, marks, an exam schedule, and announcements.

Folder: `student-dashboard/`

## Technologies
- HTML5 for page structure and content
- CSS3 for layouts, colors, cards, responsive styling, and hover effects
- No JavaScript or backend is used

## How to run
1. Open the desired project folder.
2. Double-click `index.html`, or open it in a browser.
3. To edit the project, open `index.html` and `style.css` in Visual Studio Code.

## Notes
- These are educational front-end prototypes. Forms, search fields, and action buttons are visual demonstrations and do not submit data or perform real bookings/enrollments.
- Package prices, grades, attendance, schedules, and student information are sample data for demonstration only.
- Some destination/course images are loaded from Unsplash and require an internet connection.
